Multi-Character Consistent AIGC Agent System

Core developer · Under review at ACL ARR · 2025 – Present

  • Problem: using several character LoRAs at once causes identity bleeding, attribute leakage or dropped characters. Trained a conflict-aware operator offline that rewrites each character's LoRA in parameter space, so any combination is plug-and-play with no inference-time overhead.
  • Production pipeline: an orchestrator plus message queue dispatches story, storyboard, illustration and localisation tasks; a model-scheduling layer centralises retries and fallbacks, output validation and metric logging, making every generation traceable.
  • Result: evaluated on five dimensions; with five characters in one frame, identity similarity is 30.3% above the best baseline.
